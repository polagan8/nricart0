# Design and project findings

The earlier project work included hero scroll composition, parallax and product reveals. The user specifically wanted floating text/scroll motion restored, with a prior preference against the pinned horizontal Pickle Journey. This version keeps native scrolling and implements motion with bundled GSAP/ScrollTrigger instead of a remote runtime script.

On 24 September 2026, nricart.com listed a 10 Kgs Grocery Box and several monthly grocery boxes. Its 10 kg product page showed a coming-soon screen, and its home page still included unrelated furniture/plant template content. The available browser DOM described the 10 kg image as a placeholder. A complete live box configuration flow or shipping rule could not be verified there; the custom builder and strictly-greater-than-10kg rule are implemented from the user's explicit request.
